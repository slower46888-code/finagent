# 财务报表分析入门

## 一、三大财务报表

### 1. 资产负债表
资产负债表反映企业在**某一时点**的财务状况，核心恒等式为：**资产 = 负债 + 所有者权益**。
- 资产：企业拥有或控制的、预期能带来经济利益的资源，分为流动资产（货币资金、应收账款、存货等）和非流动资产（固定资产、无形资产、长期股权投资等）。
- 负债：企业的现时义务，分为流动负债（短期借款、应付账款等）和非流动负债（长期借款、应付债券等）。
- 所有者权益：股东对企业净资产的所有权，包括实收资本、资本公积、盈余公积、未分配利润。

### 2. 利润表
利润表反映企业**一定时期**的经营成果，核心公式为：**营业收入 - 成本费用 = 利润**。
关键科目包括营业收入、营业成本、期间费用（销售费用、管理费用、财务费用、研发费用）、营业利润、利润总额、净利润。

### 3. 现金流量表
现金流量表反映企业**一定时期**的现金流入流出，分为三类活动：
- 经营活动现金流：企业日常经营产生的现金流，是判断企业"造血能力"的核心。
- 投资活动现金流：购建长期资产、对外投资等产生的现金流。
- 筹资活动现金流：借款、发行股票债券、分红等产生的现金流。

## 二、常用财务指标

| 指标 | 公式 | 含义 |
|---|---|---|
| 毛利率 | (营业收入-营业成本)/营业收入 | 产品竞争力 |
| 净利率 | 净利润/营业收入 | 整体盈利能力 |
| ROE（净资产收益率） | 净利润/净资产 | 股东资金回报率 |
| 资产负债率 | 总负债/总资产 | 财务杠杆与偿债压力 |
| 流动比率 | 流动资产/流动负债 | 短期偿债能力 |
| 每股收益 EPS | 净利润/总股本 | 每股盈利水平 |
| 市盈率 PE | 股价/每股收益 | 估值高低（需结合行业） |
| 市净率 PB | 股价/每股净资产 | 资产估值水平 |

## 三、杜邦分析体系

杜邦分析是美国杜邦公司提出的一种财务综合分析框架，其核心是把 ROE 拆解为三个驱动因素的乘积：

**ROE = 净利率 × 总资产周转率 × 权益乘数**

- 净利率反映**盈利能力**（赚不赚钱）；
- 总资产周转率反映**营运能力**（资产转得快不快）；
- 权益乘数反映**财务杠杆**（借了多少钱，权益乘数 = 总资产/净资产 = 1/(1-资产负债率)）。

举例：一家公司 ROE 为 20%，可能是靠高净利率（如高端消费品公司），也可能是靠高周转（如零售企业），还可能是靠高杠杆（如银行地产）。杜邦分析能帮助投资者看清高 ROE 背后的真正来源，判断其可持续性。

## 四、阅读财报的注意事项

1. **关注审计意见**：标准无保留意见是基本前提，非标意见需高度警惕。
2. **纵向对比**：看公司自身连续 3-5 年的趋势，而非单一年份。
3. **横向对比**：与同行业可比公司比较，避免孤立的绝对数值误判。
4. **利润质量**：利润是否匹配现金流，应收账款是否异常增长。
5. **警惕财务异常**：收入与现金流背离、存货异常堆积、频繁变更会计师事务所等。
