# 个人投资风险管理

## 一、投资者面临的主要风险类型

1. **市场风险**：因市场价格波动（股价、利率、汇率等）导致资产价值变动的风险。
2. **信用风险**：交易对手或发行方违约的风险，如债券发行人无法按期还本付息。
3. **流动性风险**：资产难以快速以合理价格变现的风险。
4. **操作风险**：因交易操作失误、系统故障等造成的损失风险。
5. **政策风险**：监管政策、行业政策变化对投资的影响。

## 二、风险承受能力评估

根据监管部门要求，投资者在开户和购买产品前需完成风险承受能力测评，结果通常分为五级：

- **C1 保守型**：适合低风险产品，如货币基金、国债；
- **C2 稳健型**：可配置债券基金、固收类产品；
- **C3 平衡型**：可适当配置混合型基金；
- **C4 成长型**：可参与股票、股票型基金；
- **C5 激进型**：可参与期货、期权等高风险品种。

投资者购买的产品风险等级（R1–R5）不应超过自身风险承受能力等级。

## 三、资产配置的基本原则

1. **分散化投资**："不要把所有的鸡蛋放在同一个篮子里"。通过配置不同资产类别（股票、债券、现金、黄金等）和不同行业，降低单一资产波动的影响。
2. **风险收益匹配**：高收益必然伴随高风险，应根据自身风险承受能力确定股票、债券等资产的比例。
3. **定期再平衡**：定期检查资产配置比例，卖出涨幅过大的资产、买入占比下降的资产，恢复目标配置。
4. **长期投资**：历史数据表明，长期持有优质资产通常能平滑短期波动带来的损失。

## 四、仓位管理与止损纪律

1. **单一标的仓位上限**：一般建议单一股票持仓不超过总资产的 20%，避免集中度风险。
2. **设置止损**：买入前预设止损线（如亏损 8%-10% 止损），避免亏损扩大和情绪化决策。
3. **避免满仓操作**：保留一定比例的现金，既可应对突发风险，也能在市场回调时获得补仓机会。
4. **谨慎使用杠杆**：融资融券、场外配资会放大收益的同时成倍放大亏损，普通投资者应慎用或不用。

## 五、常见投资误区

1. **追涨杀跌**：盲目追逐短期热点，高买低卖，是散户亏损的主要原因之一。
2. **过度交易**：频繁交易产生大量佣金和印花税成本，且容易放大情绪化决策错误。
3. **从众心理**：跟随市场情绪和他人推荐买卖，缺乏独立判断。
4. **忽视风险只谈收益**：只看产品宣传的预期收益，不了解其风险特征和亏损可能性。
5. **信息面狭窄**：仅凭单一消息或传言决策，不做基本面和技术面综合判断。

## 六、风险管理的建议流程

1. 评估自身风险承受能力（年龄、收入、家庭负担、投资经验）；
2. 确定投资目标和期限（短期流动性需求 vs 长期增值）；
3. 构建与风险等级匹配的资产配置方案；
4. 制定每笔投资的买入理由和止损条件；
5. 定期复盘投资组合，修正配置偏差。
